# 使用教程
首次下载后先安装 Node.js 22+ 并在工程目录运行 `npm ci`，之后双击 `启动.cmd`。在管理页保存自己的 cat-key，新建独立环境并手动登录 Google。进入 AI Studio 后关闭该账号的登录窗口，再点“完成登录并转后台”，程序会载入 Key、发送 hi 并维持反代心跳。自动 Cookie 续推默认关闭，需要在“运行设置”主动开启。
二次启动的时候可以不用重复登录。

v0.4.0 新增独立代理设置与连接失败自动重试，并兼容印地语等界面的发送按钮。若多个账号同时连接超时，请在右上角“网络设置”填写自己的代理地址后重启账号。网页管理标签可以关闭，启动 CMD 窗口与代理程序需要保持运行。

## 启动和首次登录

1. Windows、Node.js 22+、已安装 Chrome 或 Edge。首次运行先执行 `npm ci`，日常双击 `启动.cmd`。启动脚本会打开常驻控制台，持续显示服务、账号内核、执行日志和每 10 秒状态；关闭该窗口或按 Ctrl+C 会先停止全部账号内核。
2. 点击“新建独立环境”，填写名称。邮箱可以先留空，Key 留空使用已保存的共享 Key。
3. 默认勾选“保存后打开此环境的登录窗口”。登录通过普通 Chrome/Edge 进程打开，不使用 Playwright、不带远程调试或自动化参数，也不注入脚本、读取页面或载入 Key。你手动完成 Google 登录、验证及 AI Studio 的正常页面提示。
4. 进入 AI Studio 聊天页后，先正常关闭此账号的全部登录窗口，让浏览器保存会话，再在账号台点击“完成登录并转后台”。工具使用同一专属目录启动无窗口内核，之后才验证网页、邮箱、WAA 和反代连接。关闭窗口本身不代表登录成功。
5. 后续点“后台启动”即可；若登录失效，使用“登录 / 更新登录”。每个环境仅登录一个 Google 账号，避免账号识别冲突。

普通登录窗口没有自动化调试连接，因此登录时不提供页面预览、脚本激活或网页检查。若页面仍显示“浏览器或应用可能不安全”，停止重试，按 Google 的正常支持/账号验证流程处理；本工具不保证普通窗口能消除 Google 风控，也不添加隐藏 webdriver、伪装指纹或降低浏览器安全性的设置。

会话保存在 `.data/runtime-profiles/<账号ID>/Default`；运行偏好和账号备注也在 `.data`。保留此目录，勿分享给别人。源码副本不包含任何此类私人数据。若旧版本遗留导入记录，会自动退役到本机 `.data/backups/`，不再使用旧导入环境。

## 下次手动启动

1. 双击原先保存账号的工程内 `启动.cmd`。服务仍在运行时只重新打开管理页，不会重复启动账号。
2. 如果电脑重启或服务已退出，打开管理页后点击“全部后台启动”，也可逐个点“后台启动”。服务启动本身不会自动启动账号。
3. 同一 Windows 用户和同一 `.data` 目录下，Key 与账号会话会继续保留，一般不必重新输入或登录。后台会按保存的设置发送一次 hi 激活并维持心跳。
4. 只有登录过期时才点“登录 / 更新登录”，手动完成登录、关闭该环境全部窗口，再点“完成登录并转后台”。
5. 管理页标签可以关闭；账号台服务进程必须保留，电脑不能睡眠或关机。不要同时用登录窗口和后台内核打开同一账号环境。

不要用本源码副本替代原运行目录来恢复现有账号；两个目录的数据彼此独立。

启动文件使用 ASCII 内容与 Windows CRLF 换行，避免中文批处理被误读成命令。启动检查为英文，Node 服务运行日志仍为中文；缺少依赖或服务出错时会停留在窗口中，按任意键才关闭。修改 `启动.cmd` 时请保留 CRLF，不要改成只有 LF 的换行。`npm test` 包含真实 `cmd.exe` 入口、中文/空格路径、参数传递和错误窗口等待测试。

## 后台功能

- 单账号或全部后台启动、停止；重启内核。
- 自动发送一次 hi 激活、捕获 WAA、注册反代；约 20 秒 ping/pong 心跳。
- 自动激活根据提示框内的运行组件和发送图标识别按钮，兼容印地语等本地化界面；停止、取消、禁用及无法唯一识别的按钮不会自动点击。
- 可手动立即推送云端；本副本默认关闭自动 Cookie 上传。主动启用后，默认约 45 分钟续推，失败约 15 分钟重试。间隔可设置为 10–1440 分钟。
- 日志、手动页面预览、重载网页、运行设置、归档/恢复。
- 异常退出最多尝试恢复 3 次。运行设置/Key 更新后需重启生效。

控制台分别显示内核、WAA、注册和心跳应答。WAA 未就绪时不注册或自动推送。关闭管理标签页不影响后台；退出账号台服务、系统睡眠或关机会中断。不会自行添加开机任务或更改电源设置。

## 网络连接

若多个账号一起出现 `ERR_CONNECTION_TIMED_OUT`，在右上角“网络设置”选择“指定代理”，填写代理实际监听地址，例如 `http://127.0.0.1:10090`，保存后重启账号。代理地址需要自行配置，本源码副本不包含原运行环境的配置。设置保存在 `.data/network-settings.json`，重启账号台后仍保留；本机代理程序必须保持运行。

指定代理同时用于后台网页、WebSocket 心跳、脚本更新和 Cookie 续推，普通手动登录窗口也使用同一地址。支持无需认证的 HTTP、HTTPS、SOCKS5 代理，不修改 Windows 全局代理。“跟随系统代理”保持浏览器默认行为，后台更新和推送请求默认直连；系统代理关闭时浏览器也使用直连。“直接连接”显式禁用浏览器代理。需要全部流量使用同一代理时请选择“指定代理”。

页面连接失败后显示“连接失败 · 等待重试”，按 15、30、60、120 秒的间隔重新打开 AI Studio，此后最多每 120 秒重试一次，连接成功后重置。手动“重新载入页面”同样打开 AI Studio 目标地址，避免反复刷新浏览器错误页。页面重载会清除旧的 WAA 和连接状态，实际心跳以收到 pong 为准。

## 凭证与隐私

Key 使用当前 Windows 用户 DPAPI 加密保存。管理页面只返回尾号；启动时经内存/子进程通信载入，不写入启动参数、源码或明文账号 JSON。不持久保存脚本捕获的授权请求头。

本源码副本默认关闭自动云端续推。仅在信任后端时，到账号“运行设置”主动开启后重启：这会把此运行账号的 Google 登录 Cookie（包括 HttpOnly）发到固定 catiecli 后端。Cookie 等同登录凭证，手动点击“立即推送云端”也会上传。识别不到邮箱或与账号备注不符时拒绝云端上传。关闭 Cookie 自动上传不等于关闭反代注册，所填 cat-key 仍用于连接后端。

账号台只监听 127.0.0.1，并校验随机令牌和来源。不要分享带令牌的控制台地址。页面预览可能显示个人信息。归档停止并隐藏账号，但不删除其持久目录或 Key。
